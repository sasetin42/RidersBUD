=========================================
RIDERSBUD ANDROID RELEASE KEYSTORE INFO
=========================================

To securely sign the application for release on Google Play Store, generate a release key on your local machine using Java's keytool utility.

Generate Command:
-----------------
keytool -genkey -v -keystore release-key.jks -keyalg RSA -keysize 2048 -validity 10000 -alias ridersbud-key

Recommended Credentials Strategy:
--------------------------------
- Keystore file name: release-key.jks
- Key alias: ridersbud-key
- Store password: [Set Secure Store Password]
- Key password: [Set Secure Key Password]
- Location: Place the resulting 'release-key.jks' inside this '/playstore-release/keystore/' folder for easy gradle referencing.

⚠️ IMPORTANT WARNING:
---------------------
DO NOT LOSE THIS KEYSTORE OR PASSWORDS. Google Play Console utilizes this signature to verify future application updates. If the keystore file or key passwords are lost, you will not be able to publish updates or release new features to your users. Keep this folder backed up in a secure, encrypted vaults/passwords manager.
