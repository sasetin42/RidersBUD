# RidersBUD Production Android Release Keystore Metadata

Keystore Filename: release-key.jks
Key Alias: ridersbud-alias
Keystore Location: ./playstore-release/keystore/release-key.jks

Important Warnings:
1. DO NOT lose this keystore file or key credentials. Google Play Console requires the SAME keystore and key signature for all future application updates. Losing it will prevent you from upgrading the app.
2. DO NOT commit the .jks file or raw passwords to public version control. 

Signing config is managed dynamically using system variables or local credentials configured inside `android/variables.gradle`.
